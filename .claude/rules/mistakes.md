# Lessons Learned — AutoBrowser

---

## 1. Счётчик, который никогда не инкрементируется

**Что за ошибка:**
В `AgentWorkflow.plan()` счётчик переплановок писался так:
```python
"replan_count": replan_count + (1 if replan_count > 0 else 0)
```
На первом вызове `replan_count == 0`, поэтому прибавлялось 0. Значение оставалось 0 вечно.
`reflect_router` проверяет `replan_count < MAX_REPLANS` — условие всегда True → бесконечный цикл `replan → plan → replan`.

**Как избегать:**
Счётчики итераций всегда писать как `counter + 1`. Любое условие внутри инкремента (`+ (1 if ... else 0)`) — красный флаг. Перед коммитом мысленно прогнать: «что будет на первом вызове, на втором?»

## 2. Граф продолжает идти после узла, который "сигнализирует" через состояние

**Что за ошибка:**
`execute` при пустом списке шагов возвращал `{"reflection": "done"}`, рассчитывая, что граф остановится. Но жёсткое ребро `execute → mcp → observe → vision → reflect` всё равно выполнялось. `reflect_node` вызывал LLM и перезаписывал `reflection` на `"replan"` — сигнал `"done"` терялся.

**Как избегать:**
Сигнализировать через состояние (`reflection`, флаги) можно только если следующий узел **читает** это значение как маршрутный роутер. Если за узлом стоит жёсткое ребро, оно выполнится безусловно.
Досрочное завершение реализуется только через `add_conditional_edges` с ветвью `END`. Никогда не полагаться на то, что «следующий узел увидит флаг и остановится» — это не так.

## 3. Промпт с escape-hatch'ем, который LLM использует по умолчанию

**Что за ошибка:**
Промпт планировщика содержал:
```
- If the request is simple, set "plan_needed" to false and leave "steps" empty.
```
LLM классифицировал «перейди на сайт» как простую задачу и возвращал `steps=[]`. Система не могла выполнить ни одного шага и уходила в бесконечный replan.

**Как избегать:**
Не давать LLM escape-hatch в промпте, если пустой результат ломает downstream-логику. Если пустой список шагов недопустим — явно запретить его: «Always create at least one step. Never return an empty plan.» Перед написанием промпта спрашивать: что произойдёт, если модель выберет самый ленивый вариант?
