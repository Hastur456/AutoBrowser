# Create AGENTS contributor guide

## Цель задачи

Создать `AGENTS.md` в корне репозитория как краткое руководство для контрибьюторов, если файл еще не существует.

## Исходный контекст

- Инструкции проекта прочитаны из `CLAUDE.md`.
- `AGENTS.md` в корне отсутствует.
- Директория `plans` существует.
- В рабочем дереве уже есть несвязанные изменения: `CLAUDE.md` и `plans/2026-07-03-ollama-langgraph-agent-from-scratch.md`.

## Принятые решения

- Не изменять существующие несвязанные файлы.
- Сначала собрать минимальный контекст о структуре, тестах, зависимостях и истории коммитов.
- Создать concise Markdown-документ на английском, как запросил пользователь.

## Пошаговый план

1. Осмотреть структуру `src`, `tests` и корневые конфигурационные файлы.
2. Проверить доступные команды разработки и тестов.
3. Посмотреть последние сообщения коммитов для рекомендаций.
4. Создать `AGENTS.md`.
5. Обновить этот план фактическими изменениями и проверкой.

## Выполненные изменения

- Создан план задачи.
- Проверено, что `AGENTS.md` отсутствовал в корне до записи.
- Собран контекст по структуре `src`, пустой директории `tests`, зависимостям `requirements.txt` и последним сообщениям коммитов.
- Создан `AGENTS.md` с contributor guide на английском языке.

## Проверка и результаты тестов

- Проверено отсутствие `AGENTS.md` перед созданием.
- Тесты не запускались, так как изменение документационное и `CLAUDE.md` требует отдельного разрешения на запуск тестов.

## Открытые вопросы или риски

- Не запускать тесты без отдельного разрешения пользователя согласно `CLAUDE.md`.
